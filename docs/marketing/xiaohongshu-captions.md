## A · 创作者 / 设计师 / 开发者向

### 标题

**主**：花了 2 周，把杭州 700 年的诗人做成了一张可交互的图

**备 1**：没有美术功底，靠 D3 做了张诗人关系图谱
**备 2**：为了搞懂白居易和苏轼到底差几年，我做了个网页

### Cover
`images/xhs-cover-C-seal.png`（朱印独立感，配创作者气质）

### 正文

钱塘水自唐流到宋，七百年里，至少 81 位我们叫得出名字的诗人在这片湖边停过。

白居易筑过白堤，苏轼后来又添了苏堤；林逋在孤山种梅葬鹤，李清照南渡寓居临安，陆游和辛弃疾也都在这里写过词。

名字我都背得出，可问他们之间隔了多少年、谁认识谁、谁与谁同朝——我答不上来。

于是花了两周，把这事做成了一张图。👇

🎨 关于设计

整个项目避开了"国风模板"那种红黑龙凤路子。色板就三主色：朱（中唐 / 重要节点）、北宋蓝、南宋绿，配米纸底 + 纸纹 + vignette 暗角。字体一律 Noto Serif SC + JetBrains Mono 双子，中文标题旁配英文拼音（BAI · JU · YI 这种），数字一律 mono。每个诗人卡右上有朱印，accent 用竖排朱字（白居易 →「白堤」/ 苏轼 →「苏堤」/ 林逋 →「梅妻鹤子」），是我最得意的小细节。

📐 关于结构

时间轴用纵向铺开（不是横向），生卒年 1:1 对应像素位置，看完一眼能感到"700 年到底有多长"。

关系图用 D3 力导向，按朝代分簇——38 条可考关系 / 20 种类型（挚友、师生、政敌/诗友、结社词友、狱中诗友……），每条线上标关系类型，推断关系会标注存疑。苏轼那一团里能看到他与王安石的政争、与黄庭坚的师生、与释道潜的方外之交，全都连成线。

🛠 技术栈

React 19 + TypeScript + Vite 6 + Tailwind v4 + D3。完全前端 SPA，无后端依赖，整个 dist 不到 500 KB（不算字体）。Apache 2.0 开源，数据 ts 文件可直接 fork 二次创作。

## B · 古诗词 / 文化分享者向

### 标题

**主**：苏轼比白居易晚了 200 多年，他们都为西湖筑过堤

**备 1**：白居易、苏轼、李清照、陆游……他们其实都来过这里
**备 2**：我把和杭州有关的 81 位唐宋诗人串成了一张图

### Cover
`images/xhs-cover-A-shanshui.png`（山水气，配文化分享者气质）

### 正文

去西湖玩，导游会指着白堤说"白居易修的"，再走一段指着苏堤说"苏轼修的"。

听完不会有什么感觉。但如果你知道这两个人相差 200 多年——白居易卒于 846 年，苏轼出生于 1037 年——就突然感到一种很奇妙的东西：这片湖记得他们俩。

📜 700 年里，和杭州有关的诗人

最近把这件事做成了一张可交互的图：唐到宋这 700 年，至少 81 位我们叫得出名字的诗词名家来过钱塘——有人在这里当过官，有人在这里隐居，有人路过题了一首诗，有人晚年漂泊到这里再没走。

——贺知章 744 年弃官还乡，"少小离家老大回"。
——白居易 822 年知杭州，主持修筑白堤。
——林逋一辈子隐在孤山种梅葬鹤，没出过仕。
——苏轼 1089 年知杭州，疏浚西湖、筑苏堤。
——李清照南渡，"寻寻觅觅，冷冷清清"是在西湖写的。
——岳飞葬于西子湖畔。
——陆游一次次过临安，写下"小楼一夜听春雨"。
——文天祥北行被俘，途中过钱塘。

🕸 真正有意思的是：他们彼此认识

时间轴看的是"谁活在哪一年"，但读诗的人都知道，真正有意思的是"谁认识谁"。

苏轼和黄庭坚是师生，与王安石是政敌也是诗友，与释道潜是方外之交。
南宋一角，陆游和辛弃疾的诗酒之交、文天祥和汪元量的狱中相伴、周密和张炎的结社联吟——是另一种相互取暖的样子。

整张图统计了 38 条有据可考的关系，20 种关系类型——挚友、师生、政敌/诗友、结社词友、狱中诗友——都摆开了。

🎁 给你的小线索

下次去西湖，可以试着按这个时间轴的顺序走一遍：白堤（白居易）→ 孤山（林逋墓）→ 苏堤（苏轼）→ 岳王庙（岳飞）。一千年的人物按时间顺序在你脚下走过一遍。

## C · 工具党 / 教学向

### 标题

**主**：唐宋诗人 81 位、700 年时间轴、关系图谱：投屏可用，备课能省半天

**备 1**：语文老师讲到"白居易和苏轼"，可以投屏直接用这张图
**备 2**：学唐宋诗，先用这张图把 81 个人的位置摆清楚

### Cover
`images/xhs-cover-B-hero.png`（4 组数字 hero，配工具党气质）

### 正文

最近做了一张可交互的网页，专门为唐宋诗词的"教 / 学 / 备课"场景。

📍 它解决一个具体问题

讲到白居易，老师会顺带提到"刘禹锡是他挚友"。讲到苏轼，会提到"他和黄庭坚、秦观、晁补之、王安石都有交集"。但学生听完，记不住——因为脑子里没有一个时间轴 + 人物网格在那里。

这张图就是那个网格。

🧰 老师能怎么用

✅ 投屏教学
讲到任何一位诗人，把网页打开，缩到那个朝代，点开他的卡片——朝代 / 生卒年 / 杭州事迹 / 流派 / 代表作 / 关系网络一屏看清。81 位诗人按生卒年纵向铺开，700 年的时间感学生一眼能体会到。

✅ 多维筛选讲专题
比如要讲"南宋词派"：勾选「南宋 + 婉约」，李清照、姜夔、吴文英、周密、张炎全筛出来；要讲"在杭州当过官的诗人"：勾选「任职 + 北宋」，苏轼、苏辙、王安石、沈括一并显示——5 大类 34 个标签可任意组合。

✅ 一键导出长图
顶栏点一下，整张时间轴压成一张 PNG，塞进 PPT 或者发到家长群当复习材料。

✅ 链接级分享
`#/poet/苏轼` 直达苏轼卡，`#/graph/白居易` 直达白居易关系网。布置作业可以直接发某个具体场景的链接。

📊 数据准不准

诗人生卒年、官职、流派、代表作主要参考《全唐诗》《全宋词》以及通行年谱、杭州地方志；38 条人物关系以可考的师承、唱和、姻亲、同朝为依据，部分推断关系会**明确标注存疑**。每次构建前会自动跑一次数据完整性校验，出错则构建失败。

📱 手机也能用

做了完整的移动端适配——西湖边游客打开就能看，不用先回家开电脑。

🆓 完全免费

Apache 2.0 开源，无广告无登录无下载。

链接评论区置顶。如果你是老师 / 学生，转给可能用得上的人就好。
